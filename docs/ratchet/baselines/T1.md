## Strategy

### T1a — `signal.SIGALRM` / `signal.alarm` (8 errors)

Read `mcp/server.py:190-220` and `300-320` first to understand the platform guard pattern. Three options, in preference order:

1. **Best**: refactor the guard to use a structural pattern ty narrows. e.g., assign `_alarm = getattr(signal, "alarm", None)` once at module top, then `if _alarm is not None: _alarm(N)`. ty narrows `is not None` reliably.
2. **OK**: per-line `# type: ignore[unresolved-attribute]` with a single comment block at the top of the function explaining the guard.
3. **Worst**: blanket `# type: ignore[unresolved-attribute]` per file or per function.

If option 1 needs more than ~30 lines of churn, option 2 is acceptable.

### T1b — optional-import errors (6 errors)

For each of the 6 sites:

1. Read 5 lines around the import. Confirm the import is conditional/runtime (inside a function, in a try/except, or guarded). If it's at module level, that's a bug — escalate.
2. Add a narrow `# type: ignore[unresolved-import]` to each import line. Justify in SUPPRESSIONS.md as "module is in `[project.optional-dependencies]`; ty resolves only the always-installed deps."
3. *Alternative for `mcp.server.fastmcp` and `openpyxl`*: if they're not yet in `[project.optional-dependencies]` but should be, add them — that's the structural fix and removes the suppression need. Check first.

Do NOT add deps to the always-installed set just to silence ty. The suppression is the correct trade-off.
