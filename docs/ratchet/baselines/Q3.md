## Plan

1. **Re-export shims** (`parts.py`, `autonumbering.py`): add `__all__` listing every re-exported name. Vulture respects `__all__` membership as "used".
2. **Signal handler** (`mcp/server.py:183`): rename `signum` → `_signum`, `frame` → `_frame`. Underscore-prefix is the standard Python convention for required-but-unused parameters; vulture honors it.
3. **Tighten the pre-commit hook**: flip from `pass_filenames: true` (per-file diff scan) to whole-`src/` strict scan with `pass_filenames: false` and `always_run: true`. Drop the "(dead code, advisory)" label — the gate now holds at zero.
