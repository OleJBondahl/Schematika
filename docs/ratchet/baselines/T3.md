## Discovery — examples are calling the API wrongly

`add_terminal()` is `(self, tm_id: str|Terminal, /, *, poles=1, ...)` — `tm_id` is **positional-only**. Examples call it as `builder.add_terminal(tm_id="X1", poles=1)`. ty rightly flags this. Real fix: change to positional `builder.add_terminal("X1", poles=1)`.

The 25 `missing-argument` errors all chain from this — ty doesn't recognise the kwarg as satisfying the positional-only parameter, so it reports the parameter as missing.

### T3b — Tests `unresolved-import` + `unresolved-attribute` (32 → 0)

These are likely:
- Test files importing optional deps (skidl, openpyxl, wireviz, etc.) that aren't installed in the canonical `uv sync` env
- Test files using attributes that ty can't resolve due to dynamic patterns (mocks, monkey-patching, fixtures)

Approach:
1. For optional-dep imports: per-line `# ty: ignore[unresolved-import]`.
2. For dynamic-attribute access: per-line `# ty: ignore[unresolved-attribute]` with a one-line reason in SUPPRESSIONS.
3. *Better*: if many test files share the same optional-dep import pattern, add `tests/**` to per-file-ignores in `pyproject.toml`'s `[tool.ty.rules]` for `unresolved-import` only. That's a single suppression covering many sites — but only if ≥10 tests share the pattern.

Commit: `refactor(wave-T3b): silence ty unresolved-import/attribute in tests`

### T3c — Tests `invalid-argument-type` / `invalid-assignment` / others (65 → 0)

Most are likely mypy `# type: ignore[arg-type]` / `# type: ignore[assignment]` comments that ty doesn't honour. Convert to `# ty: ignore[<rule>]`.

For `invalid-assignment` errors: these often mean a test is reassigning a frozen-dataclass field. The fix is either:
- Use `dataclasses.replace(obj, field=new_value)` instead of `obj.field = new_value`
- `# ty: ignore[invalid-assignment]` with a reason

For the 1 `unsupported-operator` and 1 `call-non-callable`: investigate and fix or suppress.

Walk through tests file-by-file; bundle the convert-to-ty-syntax mechanical edits in one commit, real fixes (if any) in another.

Commit(s): `refactor(wave-T3c): convert mypy ignores to ty syntax in tests`. Multiple commits OK if needed.
