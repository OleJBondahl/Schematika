## Strategy

The ANN rule set targets *library code*, not tests or examples. Annotating every pytest test function with `-> None` and `*args: object` is noise. Strategy is:

1. Add `tests/**` and `examples/**` to per-file-ignores for `ANN` — clears 2166 errors with one config change.
2. Ratchet `src/` to zero via auto-fix + manual passes.

### T4a — per-file-ignores for `tests/**` and `examples/**`

Edit `pyproject.toml`'s `[tool.ruff.lint.per-file-ignores]`. Add:

```toml
"tests/**" = ["..." existing entries ..., "ANN"]
"examples/**" = ["ANN"]
```

(Tests already have a per-file-ignore section; just append `"ANN"` to its rule list. Examples may need a fresh entry.)

Verify: `uv run ruff check src tests examples --select ANN --statistics` reports 126 errors (src only).

Commit: `refactor(wave-T4a): per-file-ignore ANN in tests/ and examples/`

### T4b — Auto-fix in `src/`

Enable `select = [..., "ANN"]` in pyproject. Then:

```bash
uv run ruff check src --select ANN --fix --unsafe-fixes
```

Ruff can infer return types for many functions:
- Functions that always return literal-typed values
- Functions that don't return anything → `-> None`
- Special methods (`__init__`, `__repr__`, etc.) — well-known signatures

The 17 ANN204 special-method errors are auto-fixable (mostly `__init__` → `-> None`). ANN201/ANN202 should pick up `-> None` for procedures.

Verify the diff is sensible (no `-> Any` inferences, no broken signatures). Run `pytest` to confirm no semantic break.

Commit: `refactor(wave-T4b): auto-add return type annotations in src/`

### T4c — Manual ANN001 / ANN003 / ANN401 in `src/`

After T4b, the residue is:
- 35 ANN001 — function args without types. Annotate them. Most should have obvious types from usage.
- 8 ANN003 — `**kwargs` without type. `**kwargs: Any` is the standard escape hatch for forwarding helpers.
- 26 ANN401 — explicit `Any` use. These are deliberate. Two options per site:
  - Real fix: replace `Any` with a more specific type (e.g. `object`, a Protocol, a Union).
  - Per-line `# noqa: ANN401` with one-line reason in SUPPRESSIONS.

Default to per-line `# noqa: ANN401` when `Any` is genuinely needed (kwargs forwarders, dynamic dispatch). Default to real fix when a more specific type is obvious.

This is the manual-judgment portion of T4. Expect 50-80 minutes of careful work across ~20 files.

Commit(s): `refactor(wave-T4c): annotate src/ function args` (split into multiple commits if helpful)

## Risk

- Auto-fix for ANN201 may infer the wrong return type if a function has multiple returns of different types. Inspect the diff carefully and prefer manual annotation over wrong auto-inference.
- ANN001 fixes that touch a public method's signature might trip the `api_style_gate.py` (no positional args except identity, etc.). Coordinate carefully — adding a type annotation shouldn't change the signature shape, just the type.
- Adding `**kwargs: Any` may shadow a previous `# type: ignore[arg-type]`-style ignore that's now redundant; remove redundant suppressions.
