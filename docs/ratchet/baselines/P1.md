### P1b — Python 3.14

`pyproject.toml`:
- `requires-python = ">=3.14"`
- `[tool.ruff].target-version = "py314"` (currently `"py312"` or default)
- `[tool.ty.environment].python-version = "3.14"` if the config key exists for ty
- `.python-version` (uv pin file) → `3.14`
- pre-commit hook config — if any hook uses Python, bump the language_version

Run `uv sync` again — uv should auto-fetch Python 3.14 if not present. Then re-run the same gates.

Drop any `from __future__ import annotations` lines that are now redundant under PEP 649 (3.14 lazy-evaluates annotations by default). Use ruff to find them: `uv run ruff check --select FA --fix`.
