## Discovery

Existing `# type: ignore[arg-type]` comments in src/ are **mypy syntax** — ty 0.0.32 doesn't honour them (T1 finding). Most of T2's "errors" are actually pre-existing intentional ignores that became visible when ty replaced mypy. The work is to convert them to ty's native `# ty: ignore[invalid-argument-type]` syntax — or, where possible, fix the underlying type issue.

## Site map

### Hot sites (multi-error, same line)

| Site | Errors | Pattern |
|---|---|---|
| `src/schematika/block/diagram.py:61` | 14 | `def block(self, label: str, **kwargs: object) -> Block: b = Block(label=label, **kwargs)`. Each typed Block param produces a ty error against `**kwargs: object`. Existing mypy ignore present but ineffective for ty. |
| `src/schematika/block/model.py:165` | 13 | Same `**kwargs: object` → `Block(...)` pattern. Existing mypy ignore. |

**Fix options for the hot sites:**
1. `**kwargs: Any` — the standard escape hatch for "I'm forwarding kwargs, don't typecheck them". Single-line change per site, removes both errors and the existing ignore.
2. Explicit keyword-only params — invasive; would change the public API's surface area.
3. TypedDict — possible but adds a class def per call site; not worth it for a 1-line forwarding helper.

**Prefer option 1.** The function signature becomes self-documenting (kwargs forwarded to Block) and ty stops complaining.

### `electrical/builder.py` — 8 sites, 1 error each

Lines 286, 294, 523, 529, 708, 714, 892, 899. All have:

```python
self.connect(
    relative_to,  # type: ignore[arg-type]
    ...
)
```

where `relative_to: ComponentRef | PortRef | None` but `connect()` expects `PortRef`. Existing mypy ignore present.

**Fix options:**
1. Narrow to `# ty: ignore[invalid-argument-type]` — preserves the intent of the existing mypy ignore in ty's syntax.
2. Add a runtime assertion: `assert isinstance(relative_to, PortRef)` then ty narrows. Adds `S101` per pyproject's per-file-ignore unless src is also covered (it isn't — only tests).
3. Type-narrow at the call site with `if isinstance(...)` — invasive.
4. Widen `connect()`'s signature to accept `PortRef | ComponentRef` and dispatch internally.

Option 1 is the minimum-risk choice. Option 4 is more correct but is a public-API change and should land via a separate refactor wave.

## Caveat: existing mypy `# type: ignore` comments

There are unknown numbers of `# type: ignore[<rule>]` comments throughout the codebase that ty silently doesn't honour. If a T2 fix touches a line whose mypy ignore is now redundant (because the underlying code is type-correct under ty), DROP the comment. Don't leave dead noise. Keep a count of removed-mypy-ignores in the commit message.
